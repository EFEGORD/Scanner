# Etiqueta de privacidad (App Store Connect › Privacidad de la app)

Apple no la expone en la API: se llena a mano una vez. La app **no** recopila nada (los
documentos nunca salen del iPhone); lo que se declara es lo que recopila el SDK de anuncios de
Google (AdMob), igual que en UltraVocal y según la guía de Google
(developers.google.com/admob/ios/privacy/data-disclosure).

1. **¿Recopilas datos de esta app?** → Sí, recopilamos datos.
2. Tipos de datos (marca solo estos):

| Categoría › Tipo | Uso | ¿Vinculado al usuario? | ¿Para rastreo? |
|---|---|---|---|
| Identificadores › ID del dispositivo | Publicidad de terceros, Analítica | No | **Sí** |
| Datos de uso › Interacción con el producto | Publicidad de terceros, Analítica | No | No |
| Datos de uso › Datos de publicidad | Publicidad de terceros | No | **Sí** |
| Ubicación › Ubicación aproximada (por IP) | Publicidad de terceros | No | No |
| Diagnóstico › Datos de fallos | Analítica | No | No |
| Diagnóstico › Datos de rendimiento | Analítica | No | No |
| Diagnóstico › Otros datos de diagnóstico | Analítica | No | No |

3. **No** marques: contenido del usuario (fotos, documentos), contactos, información
   financiera, salud, búsquedas, nombre ni correo. Nada de eso sale del teléfono.
4. El "rastreo" solo ocurre si el usuario lo permite en el aviso de iOS (App Tracking
   Transparency) que la app muestra antes del primer anuncio.

URL de la política de privacidad: https://ultratools.claudita.com.mx/ultrascanner/privacidad
